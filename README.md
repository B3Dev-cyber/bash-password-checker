#BASH PASSWORD STRENGTH CHECKER BY B3!

This is a bash script that checks if a password meets basic password requirements. Simple script.

## Requirements

A password has to:
- Be at least 12 characters long
- Contain at least 1 number
- Contain at least one uppercase letter

## What I learned

I learned most of the basic syntax with linux here, experimenting with the variables/regex patterns. I also learned a whole lot from debugging the code as I was running into some permission errors,
as well as some actual errors generated from the code!
